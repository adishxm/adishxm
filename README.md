# Hi, I'm Aditya

I build tools for software reliability and security—from AI test and dependency verification to cryptographic discovery, space mission compliance, and forecast-risk analysis.

## Start here

- **[MockGuard](https://github.com/adishxm/mockguard)** — A developer tool and CI guardrail detecting AI-generated tests that test mocks instead of real application behavior using static AST analysis and mutation testing. TypeScript.
- **[OrbitScore](https://github.com/adishxm/orbitscore)** — A source-linked mission evidence organization and debris-mitigation copilot for small spacecraft teams with deterministic compliance evaluation. Python / FastAPI / TypeScript.
- **[Musify-X](https://github.com/adishxm/Musify-X)** — A high-performance, zero-telemetry Android privacy browser powered by the Chromium/Brave engine with dynamic Day/Night adaptive icons and offline shields. TypeScript.
- **[phantomdeps](https://github.com/adishxm/phantomdeps)** — A pre-install verification gate for checking package and symbol claims made by AI coding agents. TypeScript.
- **[ASTRA](https://github.com/adishxm/astra)** — A cryptographic discovery and CBOM prototype. The repository includes a live demo; check its README for current scope and verification steps.
- **[Musify](https://github.com/adishxm/Musify)** — A privacy-focused native Android browser built with Kotlin and Jetpack Compose featuring zero telemetry and local content blocking.
- **[Veyra Sentinel](https://github.com/adishxm/Veyra-Know-When-Forecasts-May-Fail-VERSION-3)** — A project exploring early warnings for forecast reliability. See the repository for its current implementation, tests and reproducibility instructions.
- **[Mesh Storage Monitor](https://github.com/adishxm/Mesh-Storage-Monitor)** — An experiment in peer-to-peer storage and monitoring with Rust. Check the README for implemented components and prototype limitations.

## How I work

I like projects where a system needs to make its uncertainty, evidence or failure modes easier to inspect. I aim to document what works, how to reproduce it, and what is still experimental.
